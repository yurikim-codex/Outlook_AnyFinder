## A2 하네스 발견 결함 이력 (2026-10-06)

jsdom 시나리오 하네스(`frontend/scenarios.mjs`) 개발 중 **실 브라우저에서도 재현될 프런트엔드 결함 3건**을 발견·수정했다:

1. **검색 기록 미기록** — `store.doSearch`가 `record_history`를 보내지 않아 검색 이력이 쌓이지 않음 → 자동완성(기록)·연관 검색어가 레거시 대비 열등. 수정: `record_history: Boolean(query.trim())` 전송.
2. **자동완성 제안 크래시** — `autocomplete.suggest` 계약은 객체 배열 `[{keyword, search_count, ...}]`인데 TS 래퍼가 `string[]`으로 타입 지정, 드롭다운 렌더 시 React error #31(객체를 자식으로 렌더)로 **앱 트리 전체 크래시**. 수정: `s.keyword` 매핑.
3. **북마크 계약 불일치 + 입력창 미동기화** — `bookmark.toggle/add/list`는 `query`/`name` 필드 계약을 쓰는데 프런트가 `keyword`로 송수신(토글 실패·목록 공백). 또한 헤더 검색창이 로컬 상태만 바라봐 사이드바 북마크/연관 검색어 칩 클릭 시 입력창이 갱신되지 않음. 수정: 계약 필드 정정 + `search.params.query` 동기화 effect.

→ 3건 모두 A2 시나리오(S5/S10)가 실패하며 노출. 수정 후 11/11 PASS(2회 반복 재현 확인).
